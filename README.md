🚀 Built an AI Resume Screening Automation with n8n

I recently built an end-to-end AI-powered resume screening system using n8n + Google Forms + Google Drive + AI + Gmail.

🔄 How it works:

📋 Candidate submits a resume through Google Forms
⬇️
📄 Resume is automatically downloaded
⬇️
🔍 PDF text is extracted
⬇️
🤖 AI analyzes the candidate's resume
⬇️
📊 Candidate receives a score out of 100
⬇️
⚡ IF logic automatically decides: Shortlist / Reject
⬇️
📧 Personalized email is sent automatically

Example:

Candidate: Asif Hussain
Score: 87/100
Status: ✅ Shortlisted
Matching Skills: Python, SQL, Git
Missing Skills: FastAPI, REST API, Docker

The entire process runs automatically without manually reviewing every resume.
